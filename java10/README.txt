HƯỚNG DẪN CHẠY
1. Giải nén thư mục.
2. Mở file index.html bằng Chrome/Edge.
3. Cấu trúc:
   - index.html: trang chủ
   - gioithieu.html: trang giới thiệu
   - lienhe.html: trang liên hệ
   - style.css: toàn bộ CSS
   - images/: hình SVG trang trí
4. Website dùng W3.CSS qua CDN, vì vậy cần Internet để tải W3.CSS.
   Nếu không có Internet, giao diện chính vẫn hiển thị nhờ style.css.
